# 管理会社変更シミュレーター

IFC様の賃貸管理HP向け「管理会社変更シミュレーター」のモックです。
いくつかの質問に答えると、改善可能性のスコアと、IFCに変更した場合のサポート内容を表示します。

- 公開URL：https://kanri-simulator.vercel.app
- スコアと結果画面の仕様：[score-spec.md](score-spec.md)

## 画面の流れ

| # | 画面 | 内容 |
| --- | --- | --- |
| 1 | TOP | イラスト・「たとえば、こんなお悩み」（3つ）・3つの特長（スマホは横一列）・スタッフ4人の顔・「シミュレーションをはじめる」 |
| 2 | STEP1：お悩み | 複数選択。「その他」は自由入力（入力するとチェックが入り、文字を消すとチェックも外れる） |
| 3 | STEP2：管理状況 | 1つ選択 |
| 4 | STEP3：物件情報 | 物件種別・築年数・戸数・エリア |
| 5 | 診断中… | 約1.2秒 |
| 6 | 診断結果 | スコア・星・選んだお悩みへの対策・スタッフからひとこと・IFCがご提供できること |
| 7 | 管理会社変更の流れ | 「ほぼ“確認するだけ”」の一言・6ステップの表（IFCの行を紺色で強調、スマホは横スクロール）・黄色い吹き出しで「最短3〜4週間」を伝えるスタッフ |
| 8 | 無料相談 | 無料相談でできること＋スタッフ4人・申し込みボタン・電話番号・IFCのロゴ |

## デザインのルール

**ボタンの色**

- オレンジ：申し込みフォームへ進むボタン（無料相談画面の「無料相談を申し込む」のみ）
- 紺色（動きあり）：特に押してほしい画面移動のボタン（「シミュレーションをはじめる」「無料で相談する」）
- 紺色（動きなし）：通常の画面移動のボタン（「次へ」「結果を見る」など）

**イラスト**

- TOPのメインのイラストは、紺色の線画です。
- 人物は、IFCのスタッフ4人のイラスト（1：矢嶋、2：佐藤、3：小山、4：石川）を使います。画面ごとにポーズを変えています。

| 画面 | ポーズ | ファイル | 表示 |
| --- | --- | --- | --- |
| TOP | 手を振る | staff-wave-1〜4.png | 4人を横に並べる |
| 診断結果 | 手で案内する | staff-1〜4.png | 4人からランダムで1人 |
| 管理会社変更の流れ | 右を向く | staff-side-1〜4.png | 4人からランダムで1人（吹き出しの左） |
| 無料相談 | 正面 | staff-face-1〜4.png | 4人を横に並べる |

## ファイル

| ファイル | 内容 |

| top-illust.png | TOP画面のイラスト |
| staff-*.png | スタッフのイラスト（上の「イラスト」の表を参照） |

HTML・CSS・JavaScriptだけで作っています。

## 更新のしかた

1. 変更したファイルを、このリポジトリにアップロードする
2. 1〜2分で、Vercelの公開ページに自動で反映される

スマホで反映されない場合は、index.html の中の `?v=` の番号を新しくしてアップロードし直してください。
